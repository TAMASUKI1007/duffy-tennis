# 予約支援 運用手順

サイトで受け付けるのは **仮予約** です。予約の確定は **LINE公式アカウントで運営者が行います**。
システムが自動で予約を確定したり、カレンダーに書き込んだりすることはありません。

---

## 1. 受付時間を変える

編集するのは **`apply.html` の1か所だけ**です。ファイルを開いて `BOOKING_CONFIG` を探してください
（ファイルの後半、`<script>` の先頭にあります）。

```js
const BOOKING_CONFIG = {
  hours: {
    sun: { from: '12:00', to: '20:00' },
    mon: { from: '8:00',  to: '12:00' },
    tue: { from: '12:00', to: '20:00' },
    wed: { from: '8:00',  to: '20:00' },
    thu: null,                            // 木曜は受付なし
    fri: { from: '13:00', to: '16:00' },
    sat: { from: '12:00', to: '20:00' }
  },
  ...
};
```

### 書き方

- 曜日のキーは **英語3文字**：`sun` 日 / `mon` 月 / `tue` 火 / `wed` 水 / `thu` 木 / `fri` 金 / `sat` 土
- 時刻は `'8:00'` や `'12:30'` のように **シングルクォートで囲む**
- **受付をしない曜日は `null`** と書く（`thu: null` のように）

### 表示される開始時刻

レッスンは2時間なので、**受付終了時刻の2時間前が最後の開始時刻**になります。30分刻みです。

| 設定 | 表示される開始時刻 |
|---|---|
| `{ from: '8:00', to: '12:00' }` | 8:00 / 8:30 / 9:00 / 9:30 / **10:00**（12:00終了） |
| `{ from: '13:00', to: '16:00' }` | 13:00 / 13:30 / **14:00**（16:00終了） |
| `{ from: '12:00', to: '20:00' }` | 12:00 〜 **18:00**（20:00終了）の13枠 |

受付終了を過ぎて終わる時間は自動的に出ません。**「16:00まで」と書けば、レッスンが16:00を超えることはありません。**

## 2. お休みの日を追加する（大会・私用など）

同じ `BOOKING_CONFIG` の `blockedDates` に、`'YYYY-MM-DD'` の形式で足してください。

```js
  // 受付を止める日（'YYYY-MM-DD'）。初期値は空です。
  blockedDates: ['2026-10-10', '2026-10-11', '2026-12-29'],
```

- カレンダー上でその日がグレーになり、**選べなくなります**
- 日付の下に「休み」と表示されます
- 終わったら行から消せば元に戻ります

> ⚠️ 年をまたぐときは年の書き間違いにご注意ください。`2026-01-03` と `2027-01-03` は別の日です。

---

## 3. 曜日ごとに開催コートが決まっている場合

```js
  fixedCourts: {
    fri: 'グリーンテニスプラザ'
  },
```

その曜日の日時を選ぶと、

- **希望コートの入力欄とコート予約代行のチェックが消えます**
- 「開催コート：グリーンテニスプラザ」と自動で表示され、申込内容にもそのまま入ります

お客さんが別の曜日に変更すると、自動で入れたコート名は消え、入力欄が戻ります。
**お客さんが自分で入力したコート名は消えません。**

コートを追加・変更するときは行を足すだけです。

```js
  fixedCourts: {
    fri: 'グリーンテニスプラザ',
    wed: '〇〇市民コート'
  },
```

固定をやめる場合は `fixedCourts: {}` にしてください。

---

## 4. 変更したあとにすること

1. `apply.html` を保存して、GitHub に push する
2. Vercel が自動でデプロイします（1〜2分）
3. サイトを開いて、変えた曜日の日付をタップし、**表示される開始時刻が想定どおりか**を確認する

設定の書式を間違えると（カンマ忘れ・クォート忘れなど）、**申込フォーム全体が表示されなくなります。**
変更後は必ず実際の画面で確認してください。

## 5. 申込が入ってからの流れ

```
お客さんが申込フォームを送信
   ↓
  ① Supabase に保存される
  ② EmailJS で運営者とお客さんにメールが届く
   ↓
完了画面に「仮予約を受け付けました。予約はまだ確定していません。」と表示
   ↓
お客さんが緑の「LINEで申込内容を送る」ボタンを押す
（申込内容が入力済みのトーク画面が開く。送信はお客さん自身が押す）
   ↓
運営者がLINEで日程・コート・移動費・お支払い方法を案内して確定
   ↓
運営者が自分のカレンダーに手動で登録する
```

### 保存とメールの扱い

- **両方成功** … 完了画面を表示
- **片方だけ成功** … 完了画面は表示し、画面に「確認メールをお送りできませんでした」などの注意書きを出す
- **両方失敗** … **完了画面は出しません。**「もう一度お試しください。繰り返し失敗する場合はLINEから直接ご連絡ください」と案内します

お客さんがLINEボタンを押さずに離脱することもあります。**メールが届いているかどうかを必ず確認してください。**

### 注意

- **LINEの画面が開いただけでは、メッセージは送信されていません。** 送信ボタンはお客さん自身が押します
- 友だち未追加のお客さん向けに、完了画面に「友だち追加」ボタンも置いてあります
- **移動費の金額はサイトに一切表示していません。** 内容を確認のうえ、LINEでご案内してください

---

## 6. 申込データの保存先

Supabase の `applications` テーブルです。

- 申込フォームは**公開キーで追加のみ**ができます。読み取り・更新・削除はできません
- 内容を見るときは **Supabase の管理画面**にログインしてください
- 権限の設定は `db/002_rls_insert_only.sql` にあります

---

## 7. 料金の表示

対面レッスンの料金目安は次の形で表示されます。

```
対面レッスン 120分(一律)      ¥16,500
練習ボールレンタル 1カゴ       ¥1,200   ← 「あり」のときだけ
移動費(お1人分)               別途
────────────────────────
合計(移動費別)                ¥17,700
```

**移動費の金額は、お客さん向けの画面・メール・LINE本文のどこにも出していません。**
オンライン動画添削には移動費の表記を出しません。

## 8. テスト

```
npm test
```

受付時間の計算（曜日ごとの枠数・境界・受付停止日・金曜の固定コート）と、
LINEリンクの組み立てを自動で確認します。ネットワークには接続しません。

**受付時間を変更したあとも `npm test` を通してから公開すると安全です。**
