# 予約支援機能 運用手順

サイトで受け付けるのは **仮予約** です。予約の確定はLINE公式で運営者が行い、
Googleカレンダーへの登録も **運営者が手動で** 行います。システムはカレンダーに書き込みません。

---

## ⚠️ 最重要：終日予定は初期設定のままだと枠を塞ぎません

Googleカレンダーの **終日予定は、初期設定で「予定なし（free）」** になります。
遠征・終日不在などを終日予定で登録しても、**そのままでは空き枠として提示されます。**

**対処：** 終日予定を開き、「予定あり（busy）」に変更してください。
この設定をしない限り、システムはその日を空いているものとして扱います。

同様に、「予定なし」に設定された通常の予定も枠を塞ぎません。ブロックしたい予定は
すべて「予定あり」にしてください。

---

## 申込が入ったときの流れ

1. **管理者宛メールが届く**（受付番号・希望日時・コート・移動込みの時間帯つき）
2. お客さんからLINEで受付番号が届く
3. コートを確保し、日時を確定する
4. LINEで日程・コート・移動費・お支払い方法を案内して確定する
5. **確定してから**、管理者メール内の「Googleカレンダーに追加」リンクを開いて保存する

### 「Googleカレンダーに追加」リンクについて

管理者宛メールに、**往路出発〜帰着までを1つの予定**とした予定作成リンクが入っています。
クリックするとGoogleカレンダーの作成画面が開くので、内容を確認して保存してください。

- **レッスンの2時間だけを登録しないでください。** 移動時間が空いたままになり、
  別の申込がその移動時間に重なって提示されてしまいます。
- リンクは予定作成画面を開くだけです。押しただけでは保存されません。
- **確定してから**使ってください。仮予約の段階で登録すると、実際には空いている枠を塞ぎます。

---

## 仮予約の扱い

- ステータスは `pending`（相談待ち）／`confirmed`（確定）／`cancelled`（取消）。
- **相談待ちの仮予約は、移動込みの時間帯が自動で「埋まっている」扱い**になります。
  同じ枠に別のお客さんが同時に申し込むことを防ぎます。
- 相談待ちのまま **72時間** を過ぎた仮予約は、自動的に枠を解放します
  （データは残ります。ステータスは手動で `cancelled` にしてください）。
- 枠の仮押さえはしません。カレンダーに登録済みの予定が常に優先されます。

---

## 空き枠の判定ルール

| 項目 | 内容 |
|---|---|
| レッスン | 2時間固定 |
| 開始できる時刻 | 08:00〜18:00（30分刻み） |
| 終了 | 20:00まで |
| 移動 | 8:00前・20:00後でも可。ただしその時間もカレンダーが空いていること |
| 運営者手配 | 三鷹周辺。片道1時間の固定。**合計4時間**（往路1+レッスン2+復路1）の空きが必要 |
| お客さん指定 | 関東。東小金井駅からの**実際の往復経路**で判定。往路と復路の所要時間は別々に算出 |
| 余白 | 準備・片付けの余白は加算しない。予定がちょうど接する場合は重複としない |
| 表示期間 | 2日後〜30日先 |

**経路やカレンダーが取得できなかった場合、空いているとは扱いません。**
お客さんにはエラーとLINE相談の案内が出ます。

## 必要な環境変数（Vercel）

`.env.example` を参照してください。**値はチャットやコードに書かず、Vercelの環境変数に設定します。**

| 変数 | 用途 |
|---|---|
| `GOOGLE_SA_CLIENT_EMAIL` / `GOOGLE_SA_PRIVATE_KEY` | カレンダー読み取り用サービスアカウント |
| `GOOGLE_CALENDAR_IDS` | 対象カレンダーのID（カンマ区切り） |
| `GOOGLE_MAPS_API_KEY` | コート名→住所・座標の検索 |
| `RAPIDAPI_KEY` / `RAPIDAPI_HOST` | 経路検索（NAVITIME） |
| `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` | 仮予約の保存 |
| `LINE_OA_ID` | LINE公式アカウントのID（`@`から始まるもの） |

### カレンダーの共有設定

サービスアカウントのメールアドレスに、対象カレンダーを
**「予定の表示（空き時間情報のみ）」** で共有してください。
この権限では予定の件名・参加者は読み取れません。空いているかどうかだけを見ます。
